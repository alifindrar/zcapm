# Workspace Rules: ZCAPM

## Live Web Browsing
- **Always Enable Live Web Browsing**: Always use live web search and browsing tools (`search_web`, `read_url_content`, `browser_subagent`) to gather current literature, financial research (ZCAPM, asset pricing, factor models), market data, and documentation.
- When researching paywalled or academic papers, actively hunt across open-access preprints (SSRN, arXiv, RePEc, ResearchGate, author homepages).
